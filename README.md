# ระบบขอเบิกเครื่องเขียน & Control Stock (Changan Rayong)

หน้าเว็บอยู่บน **GitHub Pages** ส่วนข้อมูลเก็บใน **Google Sheet** ผ่าน **Apps Script**

## ไฟล์ในชุดนี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (แคตตาล็อก 248 รายการ, ตะกร้า, คำขอของฉัน, ผู้ดูแล/Stock) |
| `img/` | รูปสินค้า 248 รูปจาก Stationery Catalog |
| `icon.png`, `favicon.png` | ไอคอนโปรแกรม |
| `Code.gs` | โค้ดฝั่ง Google Apps Script (API + ฐานข้อมูล) |

> ถ้ายังไม่ตั้งค่า `API_URL` หน้าเว็บจะทำงานใน **โหมดทดลอง** (เก็บข้อมูลในเบราว์เซอร์, PIN = 1234) เปิดลองได้ทันที

---

## ขั้นตอนติดตั้ง

### 1) สร้าง Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `Stationery Stock`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจากไฟล์ `Code.gs` ทั้งหมด → กดบันทึก
4. เลือกฟังก์ชัน `setupSheets` → กด **เรียกใช้** (ครั้งแรกจะขออนุญาต ให้กดอนุญาต)
   → จะได้ชีต `Items`, `Requests`, `ReqLines`, `Txns`
5. ตั้ง PIN ผู้ดูแล: **การตั้งค่าโปรเจ็กต์ (⚙) → คุณสมบัติของสคริปต์ → เพิ่ม**
   `ADMIN_PIN` = รหัสที่ต้องการ (ถ้าไม่ตั้ง จะใช้ `1234`)

### 2) Deploy เป็น Web App
1. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
2. เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`

### 3) ใส่ URL ในหน้าเว็บ
เปิด `index.html` หาบรรทัด

```js
const API_URL = '';
```
ใส่ URL จากข้อ 2 ไว้ในเครื่องหมาย `' '` แล้วบันทึก

### 4) อัปโหลดขึ้น GitHub Pages
1. สร้าง repo ใหม่ใน GitHub (เช่น `stationery`) แล้วอัปโหลดไฟล์ทั้งหมด **รวมโฟลเดอร์ `img`**
2. **Settings → Pages → Branch: main / root → Save**
3. ลิงก์ที่ได้จะเป็น `https://changan-cps.github.io/stationery/`

### 5) เริ่มใช้งานครั้งแรก (ผู้ดูแล)
1. เปิดหน้าเว็บ → **ผู้ดูแล / Stock** → ใส่ชื่อ + PIN
2. กด **นำเข้า Catalog 248 รายการ** (ทำครั้งเดียว)
3. หน้า **ตรวจนับ**: กรอกยอดของที่มีจริง → บันทึก (จะเป็นยอดยกมา)
4. หน้า **Stock คงเหลือ**: ตั้ง Min / Max / ที่เก็บ → บันทึก

## การทำงานของระบบ
| ขั้นตอน | ใครทำ | ผลต่อ Stock |
|---|---|---|
| เลือกสินค้า → ส่งคำขอ (ชื่อ, รหัสพนักงาน, แผนก, Cost center) | พนักงาน | – |
| อนุมัติ / ไม่อนุมัติ (ใส่หมายเหตุได้) | ผู้ดูแล | – |
| **จ่ายของ** (แก้จำนวนจ่ายจริงได้ ระบบไม่ให้จ่ายเกินยอดคงเหลือ) | ผู้ดูแล | ตัด stock อัตโนมัติ (OUT) |
| **รับเข้า** (ใส่เลข PO/Invoice) | ผู้ดูแล | เพิ่ม stock (IN) |
| **ตรวจนับ** | ผู้ดูแล | ปรับส่วนต่าง (ADJ) |
| **ต้องสั่งซื้อ**: รายการที่คงเหลือ ≤ Min, แนะนำสั่ง = Max − (คงเหลือ − ยอดอนุมัติที่ยังไม่จ่าย), แยกตาม Supplier | ผู้ดูแล | – |
| **รายงาน**: มูลค่าการเบิกตามแผนก / รายเดือน / Top สินค้า (จากยอดจ่ายจริง) | ผู้ดูแล | – |

- พนักงานดูสถานะ ยกเลิก (ตอนรออนุมัติ) หรือกดขอเบิกซ้ำ ได้ที่ **คำขอของฉัน** โดยใช้รหัสพนักงาน
- พิมพ์ **ใบขอเบิก** (A4 มีช่องเซ็น 4 ช่อง) ได้ทุกคำขอ
- ทุกหน้าของผู้ดูแลมีปุ่ม **CSV** สำหรับเปิดใน Excel

## แก้ไขข้อมูลใน Google Sheet โดยตรง
- **ราคา / Supplier**: แก้ในชีต `Items` คอลัมน์ `priceEx`, `priceInc`, `supplier`
- **ซ่อนสินค้า**: ตั้ง `active` = `FALSE`
- **เพิ่มสินค้าใหม่**: เพิ่มแถวใน `Items` (ไม่มีรูปจะแสดงเป็นไอคอนกล่อง; ใส่รูปชื่อ `img/<รหัส>.jpg` ได้)
- ห้ามแก้ `onHand` ตรงๆ — ให้ใช้หน้า รับเข้า / ตรวจนับ เพื่อให้มีประวัติใน `Txns`

## ไฟล์แนบใบ PO
- แนบรูป/PDF ได้ในหน้า **รับเข้า** (สูงสุด 5 ไฟล์ต่อครั้ง รูปจะถูกย่อให้เล็กลงอัตโนมัติ)
- ไฟล์เก็บใน Google Drive โฟลเดอร์ `Stationery PO` (สร้างให้อัตโนมัติ, ID อยู่ใน Script Property `PO_FOLDER_ID`)
- ไฟล์ตั้งค่าแชร์เป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้ผู้ดูแลกดเปิดจากหน้า **ความเคลื่อนไหว** ได้
- ครั้งแรกหลังอัปเดตโค้ด ต้องรัน `setupSheets` 1 ครั้งเพื่อกดอนุญาตสิทธิ์ Google Drive

## ถ้าแก้ Code.gs ภายหลัง
ต้องกด **ทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** URL จะคงเดิม

## เรื่องความปลอดภัย
- PIN ใช้ป้องกันหน้าผู้ดูแลระดับพื้นฐาน ควรเปลี่ยนจาก 1234 และไม่แชร์
- ใครที่รู้ลิงก์ก็ส่งคำขอได้ และดูคำขอของรหัสพนักงานใดก็ได้ถ้ารู้รหัส
